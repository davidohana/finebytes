Filters > Case > Letters Case

Letters Case

Changes letter casing on the selected text field. Capitalize and Sentence case use the current word separator. Sentence case also uses Sentence End Characters.

Options

  • Capitalize — First letter of each word uppercased; other letters lowercased.
  • Sentence case — First letter of each sentence uppercased; other letters lowercased.
  • tOGGLE cASE — Uppercase letters become lowercase and vice versa.
  • UPPER CASE — All letters uppercased.
  • First letter up — First letter uppercased; all other letters lowercased.
  • wEiRd CaSe — Mixed casing. Chance of uppercase is set under Weird Case Settings.
  • lower case — All letters lowercased.
  • Leave lowercase (comma-separated) — Capitalize only: these words stay lowercase (for example a, an, the).
  • Percent of capital letters — Weird case only: chance each letter is uppercased (0–100).
  • Fixed Places — Weird case only: same character positions get the same case across files.

Examples

hello >>> HELLO a song for the world >>> a Song for the World hello world. next line. >>> Hello world. Next line. Hello >>> hELLO
