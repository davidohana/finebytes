What's New in this Version?

Magic File Renamer 8 is a ground-up rewrite of the classic MFR 7 desktop experience. The goals are the same — fast multi-file renaming, rich filters, live preview, presets, and tag-aware workflows — on a modern UI toolkit and .NET stack.

Highlights in Magic File Renamer 8

  • Avalonia desktop shell. The main window keeps the familiar MFR layout: File List on the left, Rename List, Available Filters, Filter Chain, and Filter Configuration — rebuilt for current Windows desktop APIs.
  • .NET 10. Engine, filters, UI, and CLI target .NET 10 instead of the .NET Framework 4.x stack used by MFR 7.
  • Filter Chain. The ordered list of filters to apply (formerly “Applied Filters” in MFR 7) is named Filter Chain throughout the UI and Help.
  • JSON configuration and presets. Preferences live in config.json under AppData; presets use the current JSON schema. MFR 7 XML presets are not migrated automatically.
  • Audio tags via TagLib. Read/write overlays for common tag families, with field-patch Apply on GO and dedicated Audio filters (Setter, ID3v2 Field Setter, Remover).
  • Image and EXIF for formatting. Formatter tokens can read image properties and EXIF metadata for renaming patterns (read-only; writing image tags is a separate future slice).
  • Rename List upgrades. Field shuttle, multi-column Auto-Sort, Before/After mode, CSV export of visible columns, and filter-driven column suggestions.
  • Undo Last as a preview session. Ctrl+Z (or Undo Last) loads reverse values from the last GO into the Rename List and clears the Filter Chain; nothing is written until you press GO again.
  • Local Help in your browser. F1 / Help → Index and Tips open HTML topics with the default OS app. Filter ? uses the same Help host.
  • CLI. A console entry point supports automated / preset-driven renaming — see Console (Automatic) Mode and Command Line Parameters.

Intentional differences from MFR 7

  • No FreeDB / freedb.org album lookup filter.
  • No shareware Register flow or Pro/Standard edition split in the UI.
  • No Google site-search box on the Help Index.
  • Explorer shell context-menu integration is not shipped yet (see debts / later releases).
  • Help content is rewritten for the Avalonia UI; older MFR 7 CHM-style pages and screenshots are not reused as-is.
