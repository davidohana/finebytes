Filters > Space > Shrink Spaces

Shrink Spaces

Collapses each run of two or more word-separator characters into a single separator. The separator comes from Space Character (default: space).

Options

This filter has no options.

Examples

a b c >>> a b c Gone__With___The_Wind >>> Gone_With_The_Wind

Second example assumes underscore as the word separator.
