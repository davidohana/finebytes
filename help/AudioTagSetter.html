Audio Tag Setter

Sets common embedded audio-tag fields on each file in one step. Values update the preview tags; Apply writes them to the files.

Checked fields are written. Gray (indeterminate) checkboxes set a field only when it is currently empty.

Options

  • Title / Artist / Album / … — Common tag fields with Set / only-if-empty controls.
  • Text values — Plain text or formatter templates when tokens are present.

Examples

(empty Title) >>> Blue Moon Revisited (existing Artist left alone when only-if-empty) >>> (unchanged)
