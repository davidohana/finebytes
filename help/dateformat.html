Date and Time Format Strings

Date/time format strings convert a date value to text. They are used by tokens such as <file-date>, <exif-date>, and <now>. Magic File Renamer uses .NET date/time format patterns (Invariant culture for formatter tokens).

Prefer filename-safe custom patterns (for example yyyy-MM-dd_HH-mm-ss). Characters such as : and / are not valid in Windows file names.

Standard format specifiers

A single letter selects a culture-defined pattern:

Specifier Name Example
d Short date 11/29/2004
D Long date Monday, November 29, 2004
t Short time 10:36 AM
T Long time 10:36:22 AM
f Full (short time) Monday, November 29, 2004 10:36 AM
F Full (long time) Wednesday, November 24, 2004 2:21:34 PM
g General (short time) 11/24/2004 2:21 PM
G General (long time) 11/24/2004 2:21:33 PM
M or m Month day November 29
s Sortable (ISO 8601) 2004-11-24T14:21:34
u Universal sortable 2004-11-24 14:21:33Z
Y or y Year month November, 2004

Custom format specifiers

Examples below use 8 Nov 2004, 4:22:18 PM:

Specifier Description Example
d / dd Day of month (1–31); dd zero-pads 8 / 08
ddd / dddd Abbreviated / full weekday name Mon / Monday
M / MM Month number; MM zero-pads 11 / 11
MMM / MMMM Abbreviated / full month name Nov / November
y / yy / yyyy Year (1–2 digits, padded 2, or 4) 4 / 04 / 2004
h / hh Hour 1–12 4 / 04
H / HH Hour 0–23 16 / 16
m / mm Minute 0–59 22 / 22
s / ss Second 0–59 18 / 18
t / tt A.M./P.M. designator (first char / full) P / PM
f…fffffff Fractional seconds (1–7 digits) —
z / zz / zzz Time-zone offset +2 / +02 / +02:00
: / / Time / date separators (often unsafe in file names) —
'…' or "…" Quoted literal text —
\c Escape next character as literal —
