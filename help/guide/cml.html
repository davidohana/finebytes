Command Line Parameters

This page documents launching the desktop UI with optional paths and flags. For the console program (mfr) that renames with a saved preset, see Console (Automatic) Mode.

Desktop UI

Launch the graphical app with optional paths and flags. Paths on the command line add items to the Rename List so you can preview and press GO in the UI. The desktop app does not accept preset, dry-run, confirm, or commit options — those belong to mfr.

Usage

Mfr.App.Ui.exe [<SOURCES>…] [--initial-folder <PATH>] [add options]

SOURCES are one or more files, directories, or filemasks (space-separated). Quote paths that contain spaces.

Startup intents

Argument / option Description
<SOURCES>… Files, folders, or wildcards that seed the Rename List (same role as console sources, without running a preset).
--initial-folder <PATH> Open the File List at this directory. Does not add paths by itself (UI-only; the console has no File List). When both sources and this option are set, sources still seed the Rename List and this path wins for File List location.

After a successful add, if --initial-folder was not set, the File List opens the folder that contains the first added item and selects that item.

Add modifiers

These options use the same names as the console. They apply only when seeding from SOURCES. When omitted, the desktop UI uses the matching Options preferences (Add files, Add folders, Add folder contents, Include hidden/system files).

Option Description
--files <yes|no> Include files from sources (when omitted: Options — Add files).
--folders <yes|no> Include folders from sources (when omitted: Options — Add folders).
-r, --recursive Expand directory sources recursively (when omitted: Options — Add folder contents).
--include-hidden Include hidden and system items when expanding sources (when omitted: Options — Include hidden/system files).

Examples

Mfr.App.Ui.exe D:\music\*.mp3 Mfr.App.Ui.exe D:\photos --files yes --folders no -r Mfr.App.Ui.exe --initial-folder D:\photos Mfr.App.Ui.exe D:\batch\a.jpg D:\batch\b.jpg --initial-folder D:\batch
