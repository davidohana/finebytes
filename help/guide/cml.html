Command Line Parameters

Magic File Renamer 8 has two command-line entry points:

  • The desktop UI — open the app and optionally seed the Rename List or browse a folder in the File List (interactive work; no automatic rename).
  • The console program (mfr) — automatic rename with a saved preset. See Console (Automatic) Mode.

Desktop UI

Launch the graphical app with optional paths and flags. Paths on the command line add items to the Rename List so you can preview and press GO in the UI. The desktop app does not accept preset, dry-run, confirm, or commit options — those belong to mfr.

Usage

Mfr.App.Ui.exe [<SOURCES>…] [--initial-folder <PATH>] [add options]

SOURCES are one or more files, directories, or filemasks (space-separated). Quote paths that contain spaces.

Startup intents

Argument / option Description
<SOURCES>… Files, folders, or wildcards that seed the Rename List (same role as console sources, without running a preset).
--initial-folder <PATH> Open the File List at this directory only (no Rename List add). UI-only; the console has no File List. When both sources and this option are set, sources still seed the Rename List and this path wins for File List location.

After a successful add, if --initial-folder was not set, the File List navigates to the first added item.

Add modifiers

These options use the same names as the console. They apply only when seeding from SOURCES. When omitted, the desktop UI uses the matching Options preferences (Add files, Add folders, Add folder contents, include hidden/system).

Option Description
--files <yes|no> Include files from sources (when omitted: Options — Add files).
--folders <yes|no> Include folders from sources (when omitted: Options — Add folders).
-r, --recursive Expand directory sources recursively (when omitted: Options — Add folder contents).
--include-hidden Include hidden and system items when expanding sources (when omitted: Options — include hidden/system).

Examples

Mfr.App.Ui.exe D:\music\*.mp3 Mfr.App.Ui.exe D:\photos --files yes --folders no -r Mfr.App.Ui.exe --initial-folder D:\photos Mfr.App.Ui.exe D:\batch\a.jpg D:\batch\b.jpg --initial-folder D:\batch

Console (mfr)

This section documents the console program (mfr). For an overview of automatic renaming, see Console (Automatic) Mode.

Usage

mfr <SOURCES>… -p|--preset <NAME> [options]

SOURCES are one or more files, directories, or filemasks (space-separated). Quote paths that contain spaces. Run mfr --help for the built-in summary.

Required

Argument / option Description
<SOURCES> One or more files, directories, or wildcards to process.
-p, --preset <NAME> Preset name from the presets file (required). Save presets in the UI first. See Save Preset.

Options

Option Description
--presets-file <PATH> Override the presets JSON file path (default: AppData finebytes MFR presets).
-o, --output-file <PATH> Write rename results as JSON to this path.
--include-hidden Include hidden and system files when expanding sources.
--files <yes|no> Include files from sources (default: yes).
--folders <yes|no> Include folders from sources (default: no).
-r, --recursive Expand directory sources recursively into subdirectories.
--continue-on-rename-error Continue committing after per-item rename errors instead of stopping at the first failure.
-c, --confirm Prompt for confirmation before applying each rename.
--dry-run Preview and report commit outcomes without changing files on disk.
-l, --log-level <LEVEL> Minimum log level: debug, info, warn, or error.
--config <PATH> Path to config.json (default: AppData). The file must exist when this option is set.
--set <KEY=VALUE> Override a config field (repeatable). Key is section.leaf; the value is everything after the first = (example: log.maxSessionFiles=200).

At least one of --files or --folders must be yes.

Exit codes

Code Meaning
0 Success (including when help/version output was requested).
1 User or configuration error (invalid arguments, missing preset, no matching sources, Preview errors, commit failure when fail-fast applies, and similar).
2 Unexpected application fault.

Examples

mfr C:\Music\*.mp3 -p clean --dry-run mfr C:\Music\*.flac -r -p lowercase-extension --log-level debug mfr C:\Music -p name_from_id3 -r mfr C:\Music C:\Podcasts -p my_preset --files yes --folders yes --output-file C:\Temp\mfr-results.json mfr C:\Music -p clean --config C:\Temp\config.json --set log.maxSessionFiles=50
