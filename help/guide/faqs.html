Frequently Asked Questions

Common questions about Magic File Renamer 8. Also see Tips.

Can MFR change file extensions?

Yes. Select a Filter Chain step, open its Filter Options, and set Apply To to the extension target (or include the extension in a multi-target apply). See Filter Options.

Preview looks wrong — will GO still change my files?

GO commits what Preview shows. If Auto-Preview is on, the Rename List New columns update as you edit the Filter Chain. Fix Preview first (or use console --dry-run for a no-write run). See Apply Changes and Rename List Preview.

Can I undo a rename?

Undo Last prepares a reverse preview of the last GO; disk is unchanged until you press GO again. Older operations may still be listed in the Rename Log. See Undo Last.

Where are my presets stored?

Presets are JSON under your AppData finebytes MFR folder (not MFR 7 .mps files). Manage them from the Preset Manager. See Preset Manager and Save Preset.

Can I load MFR 7 presets in MFR 8?

Not automatically. MFR 8 uses a different preset format. Rebuild Filter Chains in MFR 8 (or recreate them from the filter list) and save new presets. For renamed UI terms and filters, see Migrating from MFR 7.

Where is configuration stored? How do I reset it?

Preferences live in config.json under %AppData%\finebytes\mfr\. See Options and Reset configuration.

How do I rename from a script or Task Scheduler?

Use the console entry point with a saved preset. See Console (Automatic) Mode. Prefer --dry-run until the preview looks right.

Is there a Windows Explorer “Rename with MFR” menu?

Not in this build. Add items via the File List, drag-and-drop onto the Rename List, or pass paths to the console app. See System Requirements.

How do I open Help?

Press F1 or choose Help → Index. Help → Tips opens tips. Filter Configuration ? opens that filter’s topic. Pages open in your default browser.
