Tips

Short reminders for everyday Magic File Renamer 8 workflows.

Press F1 or choose Help → Index to open this Help in your default browser. Help → Tips opens this page.
Drag files or folders from Windows Explorer onto the Rename List to add them. You can also use Ctrl+Shift+S to add the File List selection, or Ctrl+Shift+A to add all listed items.
Press Del on a selected Rename List row to remove it from the list (it does not delete the file on disk). Ctrl+Shift+C clears the whole Rename List.
Press F2 on a Rename List cell to set a manual override. A preview cell override wins over filter output; an original-side edit is then processed by the Filter Chain.
Press F4 on a Rename List row to locate that item in the File List. Alt+Enter opens the Windows properties sheet for the focused item.
Press F5 to refresh: File List when that pane (or the main window) has focus; Rename List when its grid is focused (re-reads originals and re-runs preview when Auto-Preview is on).
Use Ctrl+↑ / Ctrl+↓ to reorder selected Rename List rows. Manual reordering turns off Auto-Sort for the list.
Shift+click a Rename List column header to add, flip, or remove a sort level. A plain header click sorts by that column alone.
Open Select fields… from the Rename List toolbar or menu to choose visible columns and Auto-Sort. Turn on Before/after mode there, then flip with Ctrl+[ / Ctrl+].
If Auto-Preview feels slow on a large list, turn preview off from the Rename List toolbar, adjust filters, then turn preview back on.
Press Ctrl+G (GO) to apply valid renames. Preview errors are warned before commit; unchanged or error rows are skipped as shown in the preview.
Ctrl+Z (Undo Last) loads a reverse preview from the last GO and clears the Filter Chain. Disk files change only when you press GO again.
Double-click a filter in Available Filters (or use Filters → Add selected filter) to append it to the Filter Chain. Select a chain step to edit its options in Filter Configuration.
Click ? on the Filter Configuration title bar to open that filter’s Help topic. The full catalog is under Filters.
Put Space Character early in the Filter Chain before space or casing filters that should honor a non-space word separator (for example underscore).
Most filters can target fields other than the file name — open Filter Options on the selected Filter Chain step and choose the apply target.
Use Formatter tokens for audio tags, image size, EXIF, and file properties when building pattern names. Open the Format Editor insert menu / token editor, or browse the full reference under Formatting Tokens.
Path Mover can create folder trees from patterns while renaming. Combine it with Formatter tokens when you want artist/album-style layouts.
Save a working Filter Chain as a preset so you can reload the same sequence later. Presets use the MFR 8 JSON format (MFR 7 XML presets are not imported automatically).
File List view modes are on the File List menu and Ctrl+1 … Ctrl+6 (Large Icons through Thumbnails).
