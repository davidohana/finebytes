Tutorial

This short walkthrough covers a typical Magic File Renamer 8 session: pick files, build a Filter Chain, preview, then apply (GO).

1. Add items to the Rename List

  • Browse with the File List on the left (path combo, back / forward / up / refresh, Mask, Exclude).
  • Select files or folders, then use Ctrl+Shift+S (Add selected) or the Rename List toolbar. Ctrl+Shift+A adds everything shown in the current folder (honoring Mask and Exclude).
  • Or drag files from Windows Explorer onto the Rename List.

2. Choose filters

  • In Available Filters, pick a group or All, then double-click a filter (or Filters → Add selected filter) to append it to the Filter Chain.
  • Select the chain step. Edit its options in Filter Configuration. Use Filter Options to set the Apply To target (name, tags, dates, and more).
  • Click ? on Filter Configuration for that filter’s Help topic, or browse Filters.

3. Preview

  • With Auto-Preview on, the Rename List updates as you change the chain. Changed cells are highlighted; preview errors appear in the status bar.
  • Use Select fields… to show the columns you care about. Before/after mode can flip originals vs preview for the same fields.
  • For large lists, turn Auto-Preview off while editing, then turn it back on.

4. Apply and undo

  • Press Ctrl+G or MFR → GO to apply valid changes.
  • Ctrl+Z (Undo Last) loads a reverse preview from the last GO; disk files change only when you press GO again.
  • Save a working chain with Save Preset for reuse.
