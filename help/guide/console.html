Console (Automatic) Mode

Console mode renames (or tags) files from the command line without the graphical UI. Use it for scripts, Continuous Integration, or Windows Task Scheduler jobs that apply a saved preset on a schedule.

Magic File Renamer 8 ships a console entry point named mfr (the Mfr.App.Cli project). It is separate from the Avalonia desktop app. Automatic renaming always requires a preset name and one or more source paths or wildcards.

Build or save the Filter Chain in the UI first (Save Preset), then call the console with that preset. The console loads presets from the default AppData presets file unless you pass --presets-file.

What it does

  1. Loads configuration (config.json) and optional --set overrides.
  2. Resolves sources into a Rename List (files and/or folders, optional recursion / hidden).
  3. Runs Preview with the preset’s Filter Chain.
  4. If Preview has no errors, commits changes (unless --dry-run).
  5. Optionally writes a JSON results file (--output-file).

If Preview reports any errors, the console aborts without committing. Session logging follows your config (same AppData log area as the UI).

Basic usage

mfr SOURCES… -p PRESET [options]

Full flag list, defaults, and exit codes: Command Line Parameters.

Examples

mfr C:\Music\*.mp3 -p clean --dry-run mfr C:\Music\*.flac -r -p lowercase-extension --log-level debug mfr C:\Music -p name_from_id3 -r mfr C:\Music C:\Podcasts -p my_preset --files yes --folders yes --output-file C:\Temp\mfr-results.json mfr C:\Music -p clean --config C:\Temp\config.json --set log.maxSessionFiles=50
