Reset Configuration

Tools → Reset Configuration deletes the AppData prefs file (config.json), skips writing session on close, and restarts the app. Named presets and local rename logs are kept.

  • After reset, options, window layout, File List session bits, and per-filter add defaults return to first-launch values.
  • To reset only one filter’s options, use ↺ on Filter Configuration instead.
