Filters > Attributes > Attributes Setter

Attributes Setter

Sets or clears read-only, hidden, archive, and system filesystem attributes. This filter edits metadata, not the file name.

Each attribute uses Set, Clear, or Keep.

Options

  • Read-only / Hidden / Archive / System — Set, Clear, or Keep for each flag.

Examples

(file without Hidden) >>> (Hidden added on Apply) (file with Archive, Clear Archive) >>> (Archive cleared on Apply)
