File Name Tokens

Tokens that read path and name parts from the current Rename List item (preview values).

File Extension

Extension after the last period, without the period. Alias: ext.

Signature: <file-extension> or <ext>

File Name

Name without extension.

Signature: <file-name>

Full File Name

Name including extension, without directory.

Signature: <full-name>

Full Path

Absolute path including full name.

Signature: <full-path>

Parent Folder

Ancestor folder segment at a 1-based level (1 = immediate parent). Empty when the level exceeds path depth. Default level is 1.

Signature: <parent-folder> or <parent-folder:level>

Rename List column Parent Directory is the absolute containing path; this token returns a single folder name segment.

File/Folder

File or Folder.

Signature: <file-or-folder>

File Name Numeric Value

First digit run in the full name, or 0.

Signature: <file-name-numeric-value>

File Name Length

Character length of the preview full name.

Signature: <file-name-length>

Full Path Length

Character length of the preview full path.

Signature: <full-path-length>

Examples

For C:\Medical Data\apr03\patients\A-D.mdf:

Token Value
<file-extension> mdf
<file-name> A-D
<full-name> A-D.mdf
<parent-folder:1> patients
<parent-folder:2> apr03
<parent-folder:5> (empty)
