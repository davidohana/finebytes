Nearby / GeoNames Tokens

Reverse-geocode GPS coordinates from image EXIF into nearby place names via the online GeoNames findNearby service. GPS itself comes from <exif-gps-lat> / <exif-gps-lon>. Nearby Country / Region / Place also appear under Jpeg Tag Rename List columns.

Name Signature
Nearby Place <geo-place>
Nearby Region <geo-region>
Nearby Country <geo-country>

Example: <geo-place> - <exif-date:yyyy-MM-dd>

Empty vs error

  • No GPS on the image → the token expands empty (no network call).
  • Successful lookup with a blank field → that token expands empty.
  • Network, HTTP, XML, or rate-limit failure when a geo-* token or Nearby column is used → PreviewError (or a Rename List load error for that row).

Account and cache

Options → Location → GeoNames username defaults to the built-in account (fbmfr), shared across installs. Change it to your own username for a private quota — see How to get a GeoNames username. Results are cached in memory and on disk so repeated coordinates do not spend credits again. Large lists with many distinct GPS locations can exhaust the free daily quota; after a rate-limit response, further uncached lookups fail fast without more HTTP until you restart or change the Options username.
