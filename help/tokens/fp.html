Formatting Tokens

Formatting tokens let you build names from a pattern in filters that support the Format Editor (for example Formatter). A format string mixes constant text with tokens of the form <name> or <name:param1,param2,…>.

Choose a group below. Token names match the live Format Editor catalog (angle-bracket names).

  • File Properties
  • General
  • Image Properties
  • EXIF
  • Nearby / GeoNames
  • PDF Document
  • EPUB Document
