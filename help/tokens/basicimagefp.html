Image Properties Tokens

Basic image information from MetadataExtractor (JPEG, PNG, GIF, TIFF, BMP, and other supported formats). Tokens fail preview when the item is not a readable image. See also Image fields.

Name Signature
Bit Depth <image-bit-depth>
Format <image-format>
Frames Count <image-frame-count>
Height <image-height>
Horizontal Resolution <image-horz-res>
Vertical Resolution <image-vert-res>
Width <image-width>
