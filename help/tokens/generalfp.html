General Tokens

Session, generator, and meta tokens that are not tied to a single metadata group.

  • Counter — <counter>
  • Item Count — <item-count>
  • Substring — <substr>
  • Token — <token>

Now

Current UTC time. Bare <now> uses yyyy-MM-dd_HH-mm-ss. Pass a custom .NET format after the colon.

Signature: <now> or <now:format-string>

See Date and Time Format Strings.

Random Char

One uniformly random character between two single-character endpoints (inclusive). Bounds are swapped if low > high.

Signature: <random-char:low,high>

Examples: <random-char:A,Z>, <random-char:0,9>
