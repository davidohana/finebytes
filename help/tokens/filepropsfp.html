File Properties Tokens

Tokens from filesystem properties of the current item.

Date/Time

Formats a filesystem timestamp with a date/time pattern.

Signature: <file-date:format-string,date-kind>

  • format-string — see Date and Time Format Strings. May contain commas; the last comma separates date-kind.
  • date-kind — creation, lastWrite, or lastAccess (case-insensitive).

Example: <file-date:yyyy-MM-dd,creation>

For EXIF “date picture taken”, use <exif-date> instead.

Disk Label

Volume label of the drive that contains the item.

Signature: <label>

Drive Letter

Drive letter for the item’s path. Network/share paths may return $.

Signature: <drive-letter>

Folder File Count

Count of files in the item’s folder (parent folder for file rows; the folder itself for folder rows). Does not include subfolders.

Signature: <file-count>

Size

File size on disk, optionally scaled.

Signature: <file-size>, <file-size:unit>, or <file-size:unit,decimals>

  • unit — omit or auto (default), b/bytes, kb, mb, gb (case-insensitive). Auto appends a unit suffix.
  • decimals — digits after the decimal point (default 0).
