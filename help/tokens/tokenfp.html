Token

Splits a resolved source string by a separator and returns the selected part (or a range of parts).

Signature (named options, order-independent): <token:tokenNumber=1,separator=-,includeNext=false,includePrev=false,source=<full-name>>

Option Description
tokenNumber 1-based part index.
separator String used to split the source.
includeNext true/false — join from the selected part through the end.
includePrev true/false — join from the start through the selected part.
source Nested format string or literal to split.

Examples

For C:\music\13_-_Smog_-_Cold_Blooded_Old_Times.mp3:

Token Result
<token:tokenNumber=1,separator=-,includeNext=false,includePrev=false,source=<full-name>> 13_
<token:tokenNumber=2,separator=_-_,includeNext=false,includePrev=false,source=<full-name>> Smog
<token:tokenNumber=2,separator=_-_,includeNext=true,includePrev=false,source=<full-name>> Smog_-_Cold_Blooded_Old_Times.mp3
