Substring

Extracts part of another format string after it is resolved. Positions are 1-based. Negative positions count from the right (−1 is the last character). Out-of-range positions are clamped.

Signature (named options, order-independent): <substr:start=1,end=5,source=<file-name>>

Option Description
start First character index to include (non-zero).
end Last character index to include (non-zero).
source Nested format string or literal to extract from.

Examples

For C:\Example\MyTestFileName.123:

Token Result
<substr:start=1,end=5,source=<file-name>> MyTes
<substr:start=5,end=-6,source=<full-name>> stFileNam
