Replace List

Applies several search/replace pairs in order, sharing one match mode and flags. Each replacement may include formatter tokens such as &lt;counter:…&gt;.

Options

  • Entries — One pair per line: search => replacement. A lone search line removes matches.
  • Mode / match flags — Same matching rules as Replacer (literal, wildcards, or regular expression).

Examples

a.a >>> b_b 01.-.Blue.Train >>> 10_-_Blue_Train
