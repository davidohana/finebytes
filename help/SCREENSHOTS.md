# Filter help screenshots

Capture each filter’s Filter Configuration options panel and save as
`help/images/{Type}.png` (catalog type name, e.g. `SpaceCharacter.png`).

## Capture tips

1. Run the UI (`just run-ui`), add the filter, select it so Filter Configuration shows its editor.
1. Capture only the options body (or the full Filter Configuration pane) at a readable scale.
1. Prefer PNG; keep widths roughly 400–600px when practical.
1. Missing images still load: `help.css` shows a checkerboard placeholder behind broken `img`.
1. This file is **not** copied to the app output directory.
