Feature List

Magic File Renamer applies a Filter Chain to files and folders and previews the result before anything is written. GO commits names, extensions, attributes, dates, folder moves, and audio-tag updates.

Names, dates, and attributes

  • Rename files and folders, including extensions
  • Set or clear file attributes
  • Modify creation, last-write, and last-access timestamps

Audio tags

  • Common formats and tag standards: MP3 (ID3v1/ID3v2), Ogg Vorbis / FLAC, APE, Apple, ASF, RIFF, and related types where available
  • Audio Tag Setter, ID3v2 Field Setter, and Audio Tag Remover, including auto-increment track numbers and format patterns
  • Tag changes appear in the preview before GO

Path Mover

  • Relocate files into different folders as part of the same operation
  • Build folder hierarchies from patterns, for example \(artist)\(album)\(track)

Adding files

  • Browse with the File List (path combo, back / forward / up / refresh)
  • Mask and exclude filters to include or skip file types
  • Add recursively from folders, including network paths Windows can reach
  • Drag and drop onto the Rename List from Explorer or other apps

Live preview

  • Real-time preview of names, tags, dates, and attributes
  • Changed cells and predicted errors are highlighted
  • Before/after mode flips the same columns between original and preview values

Formatter and tokens

  • Pattern-rename text fields, including audio tag text, from user-defined formats
  • Audio tag fields and MPEG / media properties
  • Image properties (width, height, format) and JPEG / EXIF metadata (read-only)
  • File dates, size, parent folder, counters, random characters, and session counts

Filters

  • Case, space, trimming, replace, formatting, audio, attributes, and misc groups
  • Filters can target any writeable field (name, extension, tags, and others)
  • Full catalog: Filters

Rename List

  • Choose visible fields, including audio, dates, and EXIF
  • Sort by one or more columns
  • Export visible columns to CSV
  • Manual cell override with F2

Presets

  • Save a Filter Chain (ordered filters plus options)
  • Reload the same chain later

Undo and history

  • Undo Last loads a reverse preview from the last GO
  • Disk is unchanged until GO is pressed again
  • Rename Log records past operations

Console automation

  • Command-line / console mode for automated renaming with presets
  • See Console and parameters
