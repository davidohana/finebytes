Feature List

  • Can modify names, extensions, attributes, and dates (creation / last write / last access) for files and folders.
  • Modify tags for audio files.
    • Common audio formats and tag standards are supported (for example MP3 with ID3v1/ID3v2, Ogg Vorbis / FLAC, APE, Apple, ASF, and RIFF-style tags where available).
    • Preview shows planned tag changes before you press GO.
  • Path Mover can relocate files into different folders and build folder hierarchies from patterns (for example \(artist)\(album)\(track)).
  • When adding files, you can:
    • Browse with the built-in File List (path combo, back / forward / up / refresh).
    • Use mask and exclude filters to include or skip file types.
    • Add recursively from folders, including network paths Windows can reach.
    • Drag and drop files onto the Rename List from Explorer or other apps.
  • Shows a real-time preview of expected results, including changes to audio tags, dates, and attributes. Highlights changed cells and predicted errors.
  • Powerful pattern renaming (Formatter) lets you rewrite text fields — including audio tag text — from patterns you define. Properties you can use as tokens include:
    • Audio tag fields and MPEG/media properties
    • Image properties (width, height, format, and related facts)
    • JPEG / EXIF metadata (read-only for formatting)
    • Basic file properties: dates, size, parent folder, file count, and more
    • Counters, random characters, and session item counts
  • String-processing filters can target any part of a name or other writeable field (for example uppercase only the first token, using - as a separator).
  • Case, space, trimming, replace, formatting, audio, attributes, and misc filter groups — dozens of filters in total. See Filters.
  • Audio Tag Setter, ID3v2 Field Setter, and Audio Tag Remover for embedded tags, with auto-increment track numbers and format patterns where supported.
  • Presets let you save a Filter Chain (ordered filters plus options) and reload it later.
  • Rename List lets you choose visible fields (including audio, dates, EXIF, and more), sort by one or more columns, export visible columns to CSV, and manually override cells with F2.
  • Before/after mode can flip the grid between original and preview values for the same fields.
  • Undo Last prepares a reverse preview from the last GO (disk is unchanged until you press GO again). Rename Log keeps history of past operations.
  • Options dialog for preferences; configuration lives under your AppData finebytes folder.
  • Local Help opens in your default browser (F1 / Help menu). Filter Configuration ? opens that filter’s topic.
  • Command-line / console mode for automated renaming with presets (Console, parameters).

Features from MFR 7 that are not in this build (for example FreeDB album lookup and Explorer shell context-menu integration) are omitted here on purpose. They may return in a later release. See Migrating from MFR 7 for renames and replacements.
