Feature List

Magic File Renamer batches rename files and folders, update attributes and dates, and write audio tags — with a live preview before anything hits disk.

Names, dates, and attributes

Change names, extensions, attributes, and creation / last-write / last-access dates for files and folders in one pass.

Audio tags

Edit tags for common formats (MP3 ID3v1/ID3v2, Ogg Vorbis / FLAC, APE, Apple, ASF, RIFF, and more). Use Audio Tag Setter, ID3v2 Field Setter, and Audio Tag Remover — including auto-increment track numbers and format patterns where supported. Preview shows planned tag changes before GO.

Path Mover

Relocate files into other folders and build hierarchies from patterns, for example \(artist)\(album)\(track).

Adding files

Browse with the built-in File List (path combo, back / forward / up / refresh). Mask and exclude filters control what is included. Add recursively — including network paths Windows can reach — or drag and drop from Explorer.

Live preview

See expected results in real time for names, tags, dates, and attributes. Changed cells and predicted errors are highlighted. Before/after mode flips the same columns between original and preview values.

Formatter and tokens

Pattern renaming rewrites text fields — including audio tag text — from patterns you define. Tokens can pull audio and media properties, image facts, JPEG / EXIF metadata (read-only), file dates and size, parent folder, counters, random characters, and session counts.

Filters

Case, space, trimming, replace, formatting, audio, attributes, and misc groups — dozens of filters you can chain and target to any writeable field. See Filters.

Rename List

Choose visible fields (audio, dates, EXIF, and more), sort by one or more columns, export visible columns to CSV, and override cells with F2.

Presets

Save a Filter Chain (ordered filters plus options) and reload it later for repeat jobs.

Undo and history

Undo Last prepares a reverse preview from the last GO; disk is unchanged until you press GO again. Rename Log keeps a history of past operations.

Options and Help

Preferences live under your AppData finebytes folder. Local Help opens in your browser (F1 / Help menu); Filter Configuration ? opens that filter’s topic.

Console automation

Command-line / console mode runs automated renaming with presets. See Console and parameters.
