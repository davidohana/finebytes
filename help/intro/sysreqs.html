System Requirements and Installation

Minimum system requirements

  • Microsoft Windows 10 or later (64-bit). Magic File Renamer 8 is a Windows desktop application.
  • Some installers need the free Microsoft .NET 10 Desktop Runtime; a self-contained build already includes it. Follow the notes that came with your download.

Installation

  • Install from the package you received (setup program or portable folder). Follow the instructions that accompany that package.
  • Do not install MFR 8 into the same folder as an existing MFR 7 (or earlier) installation. Keep versions in separate directories so program files do not overwrite each other.
  • After install, launch Magic File Renamer from the Start menu shortcut, desktop shortcut, or the application executable in the install folder.
  • On first launch the app writes preferences under %AppData%\finebytes\mfr\ (for example config.json). Presets and logs use the same finebytes data area.

Uninstallation

  • If you used a setup program, uninstall from Windows Apps & features / Installed apps.
  • Removing the program does not always delete AppData preferences, presets, or logs. Delete the finebytes MFR folder under AppData if you want a clean slate.

Version compatibility

  • MFR 8 is a new product generation. It does not load MFR 7 XML presets or the old shared configuration layout. Prefer exporting or re-creating presets in MFR 8. See Migrating from MFR 7 for the old→new feature map.
  • MFR 7 and MFR 8 can sit side-by-side on the same PC when installed in different folders. Shortcuts and window titles include version information so you can tell them apart.
  • You can keep MFR 7 installed while you move workflows to MFR 8, then uninstall the older version when you no longer need it.

Windows Explorer context menu

Explorer right-click (“Rename with MFR…”) integration from MFR 7 is not enabled in this build. You can still add files by browsing in the File List or by dragging items onto the Rename List.
