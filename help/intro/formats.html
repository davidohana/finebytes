Supported Formats

Magic File Renamer can rename any file or folder Windows can see. This page lists the formats where MFR also reads or writes embedded metadata — audio tags, image and EXIF facts, document Info, and media stream properties — for the Rename List, Formatter tokens, and related filters.

Unsupported or unreadable metadata on a row surfaces as a preview error for that item; other items in the list continue as usual.

Audio tags (read and write)

Embedded audio tags load and save through TagLibSharp. Generic fields (title, artist, album, and so on) work across these containers; format-specific targets (for example an ID3v2 frame on a FLAC file) fail preview when the container cannot hold that tag type. See Audio Tag Setter, Audio Tag tokens, and Audio Tag fields.

Container Typical extensions Tag blocks Default when empty
MP3 (MPEG) .mp3 ID3v1, ID3v2 ID3v2 (v2.3)
FLAC .flac Xiph comment, APEv2 Xiph
Ogg .ogg, .opus, Ogg FLAC Xiph comment Xiph
MP4 / M4A .m4a, .mp4, .m4b Apple / iTunes Apple
WMA / ASF .wma, .asf ASF ASF
WAV (RIFF) .wav RIFF INFO RIFF INFO
Monkey’s Audio .ape APEv2 APEv2

MPEG audio-header details (bitrate, layer, VBR, and related values) are available as read-only MP3 Properties on files that expose an MPEG audio header.

Image properties and EXIF (read-only)

Raster size, bit depth, DPI, frame count, format name, and EXIF camera fields come from MetadataExtractor. There is no write path for these values in the current build. See Image Properties tokens, EXIF tokens, and Image / EXIF Rename List fields.

Format Typical extensions Notes
JPEG .jpg, .jpeg Dimensions and EXIF when present
PNG .png Dimensions; EXIF when embedded
GIF .gif Dimensions and frame count
BMP .bmp Dimensions
TIFF .tif, .tiff Dimensions; EXIF when present
ICO .ico Dimensions and frame count
WebP .webp Dimensions; EXIF when embedded
HEIF .heic, .heif Still images; not camera RAW

Other types MetadataExtractor can open (for example MP3 or MP4) are not treated as images here — image and EXIF tokens still fail preview on those files.

Document Info (read-only)

PDF, EPUB, and Office package Info fields are read-only. Missing fields expand empty after a successful open; wrong type or corrupt files fail preview. There is no write path.

Format Typical extensions Source Notes
PDF .pdf PdfPig Info dictionary and page count. See PDF Document tokens and fields.
EPUB .epub VersOne.Epub Dublin Core package fields (title, creator/author, publisher, language, literal date, identifier, subject, description). Multi-value DC lists use the first non-blank entry only. See EPUB Document tokens and fields.
Office (DOCX) .docx DocumentFormat.OpenXml PackageProperties (title, author from Creator, subject, keywords, category, description, last modified by, created, modified). See Office Document tokens and fields.

Media stream properties (read-only)

MIME type, duration, audio stream facts, and video frame size come from TagLib for containers it can open — including the audio formats above and common video containers such as MP4 / M4V and ASF / WMV when TagLib recognizes the file. Raster photo size uses the Image path instead. See Media tokens and Media Properties fields.

Names, dates, and attributes

Changing names, extensions, folder location (Path Mover), file attributes, and timestamps is not limited to the formats in this page. Any path Windows can rename or update is eligible; metadata columns and tokens simply stay empty or error when a format is outside the lists above.
