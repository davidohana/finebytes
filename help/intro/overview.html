What is Magic File Renamer?

Magic File Renamer (MFR) is a powerful multiple file renamer and audio file tagger. With MFR you can change names, dates, and attributes for files and folders, and update tags for many popular audio formats.

MFR offers an extensive set of filters you can chain together to perform almost any renaming task you can think of, saving many hours of manual renaming. Among the filters is a powerful pattern-renaming (Formatter) capacity that can pull data from text, audio, video, and image files in many popular formats.

Advanced users will find MFR's flexible yet approachable interface hard to come by. Real-time preview for any field, presets, logging, undo of the last operation, and a command-line console for automated processing are part of that toolkit. MFR is built for heavy-duty renaming, including large batches, and is optimized for speed.

If you are a music collector, musician, graphic artist, photographer, digital camera owner, programmer, system administrator, or file collector of any kind, MFR is built for your workflow.

This version (Magic File Renamer 8) is a rewrite of the classic MFR 7 desktop app on a modern Avalonia UI and .NET stack. See What's New and the Feature List for what ships today.
