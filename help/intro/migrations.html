Migrating from MFR 7

Magic File Renamer 8 keeps the same batch-renaming ideas as MFR 7, but names, storage, and a few filters changed in the rewrite. Use the tables below to find the MFR 8 counterpart for a familiar MFR 7 feature. There is no automatic import of MFR 7 presets or settings.

Also see What's New, Version compatibility, and FAQs — MFR 7 presets.

UI and workflow

MFR 7 MFR 8 Notes
Applied Filters Filter Chain Same ordered list of filters to apply; renamed everywhere in the UI and Help.
Generate Batch Renaming File Tools → Generate Rename Script Exports pending path and attribute changes as .bat or PowerShell .ps1.
Undo Last (writes immediately) Undo Last (preview session) Loads reverse values and clears the Filter Chain; nothing is written until you press GO again.
Console / MFRC Console (mfr) See Command Line Parameters. New flags include --dry-run, -o / --output-file, and --set.
Explorer “Rename with MFR…” — Not in this build. Use the File List, drag and drop, or the console. See System Requirements.
Show Hidden (Rename List menu / Explorer) Options — include hidden / system when adding One preference drives File List visibility and Rename List add include.
Open UI with paths on the command line — Not in this build for the desktop UI. Seed the Rename List from the File List, drag and drop, or use the mfr console.

Settings and presets

MFR 7 MFR 8 Notes
XML presets (.mps) JSON presets Not imported automatically. Rebuild the Filter Chain and save a new preset.
Legacy shared config / session files config.json under %AppData%\finebytes\mfr\ Soft-loads with defaults when missing or corrupt. See Options and Reset configuration.

Filters renamed or combined

Most filters keep the same display name. These are the ones that changed. Full catalog: Filters.

MFR 7 MFR 8 Notes
Remove Duplicate Characters Shrink Duplicate Characters Same behavior; renamed in the rewrite.
Trim Spaces Left Strip Spaces Left Same behavior; renamed in the rewrite.
Trim Spaces Right Strip Spaces Right Same behavior; renamed in the rewrite.
Date Setter + Time Setter Date/Time Setter One filter with optional Set date / Set time.
Set from FreeDB — Not shipped yet. May return in a later release.

Formatting tokens and Rename List fields

MFR 7 MFR 8 Notes
Image Tag columns / <imagetag-*> Jpeg / EXIF columns; <exif-*> / <image-*> TagLib Image Tag fields (Rating, Orientation, Creator, …) are not ported. Prefer EXIF and image property tokens where they cover the same data. See Formatting Tokens and Rename List Fields.
Clipboard text token — Not shipped yet.
GeoNames / <geo-*> tokens — Not shipped yet.
WMF / EMF image property tokens — Image property tokens no longer cover WMF or EMF. WebP (and EXIF on PNG / TIFF / WebP) are supported instead where MetadataExtractor can read them.
Name List formatter parameter Name List filter Per-line names live on the filter; there is no separate Name List formatting token.

Filters whose display names match MFR 7 (for example Capitalize After, Replacer, Formatter, Audio Tag Setter) are listed under Filters — they are not repeated here.
