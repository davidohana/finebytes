What's New in this Version?

Magic File Renamer 8 is a ground-up rewrite of the classic MFR 7 desktop app on a modern UI toolkit. It keeps the batch-renaming workflow — filters, live preview, presets, and tag-aware renaming — and adds the capabilities below around the Rename List, formats, undo, scripting, and console automation.

New features

  • Rename List upgrades
    • Before/After mode — flip the same columns between original and preview values
    • CSV export of the visible columns
    • Add / Set columns from the current Filter Chain (write targets and format tokens)
    • Xiph Rename List columns (and Apply To targets) for Vorbis / FLAC / Opus-style tags
  • Broader image and audio format support
    • Formatter tokens can read WebP image properties (read-only)
    • EXIF tokens work on JPEG and also on PNG, TIFF, and WebP (still read-only)
    • Opus files use the same Xiph comment path as Ogg Vorbis / FLAC
  • Undo Last as a preview session
    • Ctrl+Z (or Undo Last) loads reverse values from the last GO
    • Clears the Filter Chain
    • Nothing is written until you press GO again
  • Generate Rename Script
    • Tools → Generate Rename Script exports pending path and attribute changes as .bat or PowerShell .ps1
  • Console automation upgrades
    • --dry-run previews commit outcomes without changing disk
    • -o / --output-file writes JSON results
    • --set overrides config keys for a run
    • See Console (Automatic) Mode and Command Line Parameters

Other changes

  • Refreshed desktop UI
    • Built with a modern UI toolkit for current Windows
    • Familiar layout: File List, Rename List, Available Filters, Filter Chain, and Filter Configuration
  • Filter Chain
    • Ordered filters to apply (was “Applied Filters” in MFR 7)
    • Same name throughout the UI and Help
  • JSON preferences and presets
    • Settings in config.json under AppData
    • Presets use JSON
    • MFR 7 XML presets are not migrated automatically

Not in this build yet / regressions vs MFR 7

The rewrite does not yet match every MFR 7 capability. These items are omitted on purpose for now and may return later.

  • Not shipped yet
    • FreeDB album lookup (Set from FreeDB filter)
    • Windows Explorer shell context-menu integration
    • Clipboard text formatter token
    • Editable image tags and <imagetag-*> tokens (EXIF / image properties stay read-only)
    • GeoNames reverse geocoding and typed GPS / <geo-*> tokens
    • Opening the desktop UI with command-line paths to seed the Rename List (use the File List, drag and drop, or the mfr console instead)
  • Format / imaging regressions
    • Image property tokens no longer cover WMF or EMF (MFR 7 did)
    • JPEG 2000 and PDF image-tag / XMP reading from MFR 7 is not in the current image allowlist
  • Other gaps
    • Drag selected Rename List rows out to Explorer (inbound drop still works)
    • Rename List “Show Last Rename Errors” list-wide view (per-row rename error details still work)
