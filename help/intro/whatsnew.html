What's New in this Version?

Magic File Renamer 8 is a ground-up rewrite of the classic MFR 7 desktop app on a modern UI toolkit. It keeps the batch-renaming workflow — filters, live preview, presets, and tag-aware renaming — and adds several capabilities around the Rename List, formatting tokens, undo, and Help.

New features

  • Rename List upgrades
    • Field shuttle to choose visible columns
    • Multi-column Auto-Sort
    • Before/After mode for the same fields
    • CSV export of visible columns
    • Column suggestions from the current Filter Chain
  • Image and EXIF in Formatter patterns
    • Tokens can read image properties and EXIF metadata
    • Read-only in this version
  • Undo Last as a preview session
    • Ctrl+Z (or Undo Last) loads reverse values from the last GO
    • Clears the Filter Chain
    • Nothing is written until you press GO again
  • Local Help in your browser
    • F1 / Help → Index and Tips open HTML topics in your default browser
    • Filter Configuration ? opens that filter’s topic
  • Console mode
    • mfr runs automated, preset-driven renaming
    • See Console (Automatic) Mode and Command Line Parameters

Other changes

  • Refreshed desktop UI
    • Built with a modern UI toolkit for current Windows
    • Familiar layout: File List, Rename List, Available Filters, Filter Chain, and Filter Configuration
  • Filter Chain
    • Ordered filters to apply (was “Applied Filters” in MFR 7)
    • Same name throughout the UI and Help
  • JSON preferences and presets
    • Settings in config.json under AppData
    • Presets use JSON
    • MFR 7 XML presets are not migrated automatically
