Software components

Magic File Renamer 8 uses (among others):

  • Avalonia UI — desktop user interface.
  • TagLib# — reading and writing metadata in many audio and image formats.
  • MetadataExtractor — image and EXIF property extraction (Drew Noakes and contributors).
  • PdfPig — PDF document Info and page-count reading (UglyToad and contributors).
  • VersOne.Epub — EPUB Dublin Core package Info reading (vers-one and contributors).
  • Serilog — application logging.
  • Spectre.Console — command-line interface for mfr.
  • .NET — Microsoft application platform.
