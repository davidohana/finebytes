Technical Support, Feedback & Contact Information

Technical support

Please try this Help (F1 / Help → Index) and the Frequently Asked Questions before contacting support.

E-mail technical support at support@finebytes.com. You can also open that address from Help → About.

When you write, include your Magic File Renamer version (shown in the window title and in About), your Windows version, and a short description of what you expected versus what happened. For rename problems, note whether Preview showed an error before GO.

Feedback

Comments, suggestions, bug reports, and feature ideas are welcome. Feedback is the best way to influence future Magic File Renamer releases.

Send feedback to support@finebytes.com, or use the product site contact options listed on www.finebytes.com/mfr.

Contact information

  • Web site: www.finebytes.com/mfr
  • Technical support: support@finebytes.com

Postal address is available on request.
