About finebytes

finebytes builds desktop tools for advanced users, developers, and organizations. Magic File Renamer is its long-running product for batch renaming, tagging, and related file workflows.

finebytes has been active since 1999. Magic File Renamer 8 is a modern rewrite of the classic MFR 7 desktop app.
