Counter

Serial number from the item’s position in the Rename List. Sort order affects numbering. The Counter filter is an alternative when you only need to prepend/append/replace with a number.

Signature: <counter> or named options, for example <counter:initial=1,step=1,padding=none,length=2,resetScope=global>

Bare <counter> uses those defaults.

Option Description
initial Start value for the first item (default 1).
step Increment per index; may be negative (default 1).
padding none (default), auto (width from list/folder scope), or fixed (pad to length).
length Digit width when padding=fixed (default 2; ignored when padding is none).
resetScope global (Rename List index) or perFolder (reset within each parent folder).
