Formatter

Replaces the entire selected field with the result of a format string. Mix literals and tokens such as &lt;file-name&gt; or &lt;counter:…&gt;. An empty format string clears the field.

Options

  • Format string — Pattern that replaces the target field. Tokens resolve from the current file/folder context.

Examples

(any previous name) >>> 01.1920x1080 report >>> report_backup

First example uses a format string like &lt;counter:…&gt;.&lt;image-width&gt;x&lt;image-height&gt;.
