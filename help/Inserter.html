Inserter

Inserts text at a fixed one-based character position. The insert text can be literal or a formatter template when it contains tokens.

Options

  • Text to insert — Literal text or a template with formatter tokens.
  • Position — One-based character index where insertion begins.

Examples

01_Mercury_Rave_-_Holes >>> 01_-_Mercury_Rave_-_Holes ab >>> a_b
