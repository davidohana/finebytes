Rename Log

MFR → Rename Log (Ctrl+Shift+L) lists past renaming operations so you can inspect details and undo from history.

  • Operations appear newest first. Selecting one shows which items and fields changed, and any commit errors.
  • The last operation in this session is always available for Undo Last, even when disk logging is limited or disabled in Options.
  • Undo from the log prepares the same reverse preview session as Undo Last: Rename List is filled with reverse values, the Filter Chain is cleared, and disk files change only when you press GO again. Items must still be at the paths recorded in the log.
