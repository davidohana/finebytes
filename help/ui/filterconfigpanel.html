Filter Configuration

Filter Configuration shows options for the selected Filter Chain step (or a short description when an Available Filters row is selected instead).

  • Some filters have no options; others embed helpers such as the Format Editor or Visual Trim Helper.
  • Edits are previewed automatically when Auto-Preview is on.
  • Title-bar 📌 saves the current options as the default for that filter type (stored in your prefs). ↺ resets the selected step to defaults. ? opens that filter’s Help page.
  • Catalog: Filters.
