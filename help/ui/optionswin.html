Options

Tools → Options (Ctrl+,) opens preferences stored in config.json under your AppData finebytes MFR folder. The dialog has three tabs: General, Rename, and Misc.

General

  • Remember window size and position — restore main window and dialogs.
  • Confirmations — restore dialogs you previously chose not to see again (Reset confirmations).
  • File List: remember last folder; include hidden/system files.
  • Masks and Exclude masks on the File List still filter what gets added.

Rename

  • Double-click in File List: Open vs Add to Rename List.
  • Rename List add mode: files, folders, or both; optional Add folder contents (recurse); remember column widths.

Undo & Rename Log

  • On the Rename tab, Rename Log can be disabled (Undo Last only), limited to N operations, or unlimited. History is used by the Rename Log dialog and Undo Last.

Misc

  • Location — optional GeoNames username for GPS place names (leave blank for the built-in account).

Tools → Reset Configuration deletes prefs and restarts — see Reset configuration.
