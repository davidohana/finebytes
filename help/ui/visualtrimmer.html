Visual Trim Helper

The Visual Trim Helper appears in trimming filter editors (for example Trim Left / Right / Between and related count/extract filters). It lets you set trim positions by selecting text with the mouse.

  • Use one Rename List item as a sample. By default the helper uses the first list item; navigate samples with the helper’s previous/next controls, or drag another item / text into the sample box. Drops use the filter’s current Apply To target when resolving Rename List cells.
  • Click or drag in the sample to mark the portion to trim or extract. The selection is adjusted to the filter’s rules (for example left-trim selections always start at the beginning), and the numeric options update.
  • Editing the numeric options updates the highlight in the helper.

Related filters: Trim Left, Trim Right, Trim Between, Extract Left, Extract Right.
