User Interface Elements

Main-window regions. Click a name for details.

  • Menu / toolbar — GO, Undo Last, Rename Log, Options, File List view modes, Rename List and Filters commands.
  • File List — browse the current folder; add files to Rename List.
  • Rename List — items to process, preview, sort, export.
  • Available Filters — filter palette by group.
  • Filter Chain — ordered filters to apply (was “Applied Filters” in MFR 7).
  • Filter Configuration — options for the selected chain step.
  • Status bar — hint text plus Items / Filters / Changes / Preview errors.
  • Options and Rename Log — Tools / MFR menu.
  • Presets / Save Preset — Filter Chain toolbar.

Dialogs such as Select fields, Filter Options, and the Format Editor open from those panes.
