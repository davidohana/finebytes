Counter

Builds a number from each item’s position in the Rename List.

  • Scope may be global or per folder.
  • Placement may prepend, append, or replace the selected text.

Options

  • Initial value / Step — Starting number and increment.
  • Padding / Length — How the number is padded (for example 005).
  • Reset scope — Global list index or per-folder index.
  • Placement — Prepend, append, or replace the target field.

Examples

Start1 Step1 Padding3 digits Placementreplace List item5th → 005

Intro >>> 005

Start0 Step1 Placementprepend Separator_ List item3rd → 2

Holes >>> 2_Holes

Start0 Step1 Placementappend Separator- List item2nd → 1

Holes >>> Holes-1
