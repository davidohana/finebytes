Counter

Builds a number from each item’s position in the Rename List (global or per folder) and prepends, appends, or replaces the selected text with that number.

Options

  • Initial value / Step — Starting number and increment.
  • Padding / Length — How the number is padded (for example 005).
  • Reset scope — Global list index or per-folder index.
  • Placement — Prepend, append, or replace the target field.

Examples

Start 1, step 1, pad to 3 digits, replace (5th item → 005)

Intro >>> 005

Start 0, step 1, prepend with separator _ (3rd item → 2)

Holes >>> 2_Holes

Start 0, step 1, append with separator - (2nd item → 1)

Holes >>> Holes-1
