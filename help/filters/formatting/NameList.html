Name List

Replaces the selected field with a line from a name list: line 1 for the first Rename List item, line 2 for the second, and so on.

Optional prefix and suffix wrap each list name and may include formatter tokens.

Options

  • Entries — One name per line; blank lines are empty names.
  • Prefix / Suffix — Text added before/after each list name (may use formatter tokens).

Examples

Entries (2nd Rename List item):

Alpha Beta Gamma old >>> Beta

Entries: Alpha; prefix <counter> - (padded to 2 digits)

track >>> 01 - Alpha
