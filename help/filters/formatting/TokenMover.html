Token Mover

Splits the selected text into tokens, then moves one token left or right.

Useful for swapping segments such as artist and title.

Options

  • Token separator string — Substring that splits the name into tokens.
  • Token number — One-based index of the token to move.
  • Positions to move — Positive moves toward the end; negative toward the start.

Examples

Separator -; move token #2 by −1

Artist-Album-Title >>> Album-Artist-Title

Separator ,; move token #2 by 3

Artist,Title,Album,Year >>> Artist,Album,Year,Title
