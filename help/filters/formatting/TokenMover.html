Token Mover

Splits the selected text into tokens using a delimiter, then moves one token left or right by a number of positions—useful for swapping artist and title segments.

Options

  • Token separator string — Substring that splits the name into tokens.
  • Token number — One-based index of the token to move.
  • Positions to move — Positive moves toward the end; negative toward the start.

Examples

Separator -; move token #2 by −1

a-b-c >>> b-a-c

Separator ,; move token #2 by 3

milk,sugar,bread,potatoes >>> milk,bread,potatoes,sugar
