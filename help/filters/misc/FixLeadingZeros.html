Fix Leading 0's

Finds digit runs and pads or trims leading zeros to a target width.

  • Shorter numbers gain leading zeros up to the width.
  • Longer numbers stay unchanged unless Strip surplus leading zeros is checked.

Options

  • Number of digits — Target digit count for each number run.
  • Strip surplus leading zeros — When checked, trim extra leading zeros from longer runs down toward the target width when safe.
