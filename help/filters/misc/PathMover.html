Path Mover

Moves items to a destination folder (required root plus optional sub-folder template).

  • Preview only changes the parent directory.
  • Folders are created and items moved on Apply.
  • Source folders are never deleted.

Options

  • Root folder — Static destination root.
  • Sub-folder — Optional path template (may use formatter tokens).

Examples

Root C:\Music; sub-folder <parent-folder>

C:\Downloads\Junkies >>> C:\Music\Junkies

Root C:\Archive; sub-folder <now:yyyy>

C:\Inbox >>> C:\Archive\2026
