Sentence End Characters

Does not change names by itself.

  • Sets which characters count as sentence ends for later Letters Case (Sentence case) and Casing List (uppercase sentence initials).
  • Until this filter runs, the default set is . ! ?.

Options

  • Characters — Characters treated as sentence ends (for example .!? or :;).

Examples

Characters: -:;, then Letters Case → Sentence case

track 1 - intro: verse two; chorus. bridge >>> Track 1 - Intro: Verse two; Chorus. bridge
