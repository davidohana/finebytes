Date/Time Setter

Sets the calendar date and/or time-of-day for a filesystem timestamp.

  • Target may be creation, last write, or last access.
  • Unchecked date or time parts keep their existing values.

Options

  • Timestamp field — Creation, last write, or last access.
  • Set date / Set time — Which parts to replace.
  • Date / Time values — The new calendar date and/or time of day.
