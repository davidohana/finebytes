Audio Tag Setter

Sets common embedded audio-tag fields on each file in one step.

  • Preview updates immediately; Apply writes tags to the files.
  • Only tag types already present on the file are updated.
  • Untagged files get the recommended type for the format (for example ID3v2 on MP3).
  • Checked — write the field.
  • Gray (indeterminate) — write only if the field is currently empty.
  • Unchecked — leave the field unchanged.

Options

  • Title / Artist / Album / … — Common tag fields with Set / only-if-empty controls.
  • Text values — Plain text or formatter templates when tokens are present (see Audio Tag Tokens).
  • Performers / genres / composers — Multiple values in one field: separate with ;.
  • Track — Number 1–255, or 0 / empty to clear.
  • Auto-increment track — Raise the track by one for each Rename List row, starting from the value you enter.
  • Year — Number 1–9999, or 0 / empty to clear.

To set a single field with a Formatter or other string filter, choose an audio-tag Apply To target instead.

For one modeled ID3v2 frame, prefer ID3v2 Field Setter.
