Replacer

Finds a search pattern in the selected text and replaces matches. The replacement may include formatter tokens such as &lt;file-name&gt; or &lt;counter:…&gt;.

Options

  • Find — Text, wildcards, or regular expression depending on Mode.
  • Replace with — Replacement text (formatter tokens expand per item).
  • Mode — Literal, wildcards, or regular expression.
  • Match case / Whole word / First only — Match flags that control which occurrences are replaced.

Examples

Find a, replace with X (literal, replace all)

aba >>> XbX

Find \d+, replace with N (regular expression, replace all)

a12bc34 >>> aNbcN
