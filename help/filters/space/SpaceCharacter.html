Space Character

Defines the word separator for filters that follow it.

  • Optionally rewrites common stand-ins (spaces, underscores, %20, custom text) to that character.
  • Later filters such as Shrink Spaces, Remove Spaces, Separate Capitalized Text, strip-space filters, and Capitalize use this separator.
  • Until this filter runs, the default is ordinary space.

Options

  • Use the following character to separate between words — Space, Underscore ( _ ), or Other (any single character).
  • Replace … Spaces / Underscores / %20's / Custom text — Rewrite checked forms to the defined space character.

Examples

Space character_ Replace%20

Gone%20With%20The%20Wind >>> Gone_With_The_Wind

Space characterspace Replace%20, spaces, and underscores

Me_And_Mom%20Too >>> Me And Mom Too

Space character- Replace custom text++

Artist++Album >>> Artist-Album

Put Space Character before any filter that should use a non-space word boundary.
