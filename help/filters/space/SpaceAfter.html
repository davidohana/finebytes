Space After

Inserts the word separator after each trigger character when it is missing.

Options

  • Characters — Characters that should be followed by the word separator (for example , !).
  • Only when next is a letter or digit — When checked, insert only if the next character is a letter or digit.

Examples

Characters,;! Only when next is a letter or digiton

Intro,Verse,Chorus >>> Intro, Verse, Chorus Wow!Amazing!! >>> Wow! Amazing!!
