Options

Tools → Options (Ctrl+,) opens preferences stored in config.json under your AppData finebytes MFR folder.

Session, File List, and Rename List

  • Remember window size and position — restore main window and dialogs.
  • Confirmations — restore dialogs you previously chose not to see again (Reset confirmations).
  • File List: remember last folder; include hidden/system files; double-click Open vs Add to Rename List.
  • Rename List add mode: files, folders, or both; optional Add folder contents (recurse); remember column widths.
  • Masks and Exclude masks on the File List still filter what gets added.

Undo & Rename Log

  • Rename Log can be disabled (Undo Last only), limited to N operations, or unlimited. History is used by the Rename Log dialog and Undo Last.

Tools → Reset Configuration deletes prefs and restarts — see Reset configuration.
