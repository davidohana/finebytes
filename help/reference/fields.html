Rename List Fields

These fields can be shown as columns in the Rename List. Use Select fields… to choose visible columns. Many fields also appear as formatting tokens — see Formatting Tokens.

Each field may support:

  • Write — editable via Manual Override / Edit as Name List, and available as a filter Apply target when the Filter Options pane offers that field.
  • Preview — a Before/After (or preview) column variant can be shown; values may also change when related writable fields change (for example File Name Length after renaming).

File Name

Basic path and name information.

Field Write Preview Description
File Name + + Name without extension.
File Extension + + Extension without a leading dot.
Full File Name + + Name including extension.
Full Path + + Absolute path including full name.
Parent Directory + + Absolute path of the containing folder. Changing it moves the item; missing folders are created on Apply.
File/Folder File or Folder.
File Name Numeric Value First number found in the full name, or 0. Useful for sorting.
File Name Length + Character length of Full File Name.
Full Path Length + Character length of Full Path.

File Properties

Field Write Preview Description
Creation Date + + Filesystem creation time.
Last Write Date + + Filesystem last-write time.
Last Access Date + + Filesystem last-access time.
Size File size in bytes (0 for folders).
Attributes + + Attribute flags in the form RHAS (Read-only, Hidden, Archive, System); - means unset.
Folder File Count Count of files in the item’s folder (parent folder for file rows; the folder itself for folder rows). Does not include subfolders.

Audio Tag

Semantic tag fields for common audio formats (MP3/ID3, Ogg, FLAC, Apple, ASF, and others via TagLib). Writable fields can be edited in the grid and targeted by audio tag filters. Multi-value fields (Artist, Album Artist, Composer, Genre) also have a matching (first) column. Tag Types is read-only and lists present tag blocks.

Core columns include Title, Artist, Album Artist, Album, Year, Genre, Track, Track Count, Disc, Disc Count, Comment, Composer, Lyrics, Copyright, Grouping, BPM, Conductor, plus MusicBrainz / MusicIP / Amazon identifiers. Matching tokens are listed under Audio Tag formatting tokens.

Media Properties

Read-only TagLib stream properties for audio and video (MIME, duration, audio stream, video frame size). Raster size is under Image.

Field Description
MIME Type Internet media type.
Possibly Corrupt Whether TagLib flagged the file as possibly corrupt.
Duration / Duration (Seconds) Media duration as formatted time or whole seconds.
Media Types TagLib media-type flags text.
Description Codec / media description.
Audio Bitrate / Sample Rate / Bits Per Sample / Channels Audio stream properties when present.
Video Width / Height Video frame size in pixels.

See also Media formatting tokens.

MP3 Properties

Read-only MPEG audio properties for MP3 files (bitrate, encoding, frequency, layer, version, mode, duration, copyright/original/protection flags, and related values). See MP3 Properties formatting tokens.

Image

Read-only basic image properties (format, width, height, bit depth, horizontal/vertical DPI, frame count) for JPEG, PNG, GIF, TIFF, BMP, ICO, WebP, and HEIF/HEIC. See Image Properties tokens.

Jpeg Tag

Read-only EXIF-derived columns commonly shown in the Rename List (Title, Subject, Author, Keywords, Comments, Date/Time taken, Make, Model, Description, Artist, Image Number, User Comment, Exposure, F-Number, ISO, Focal Length, Focal Length 35mm). For arbitrary EXIF tags use the EXIF formatting tokens.

PDF Document

Read-only PDF Info dictionary fields (Title, Author, Subject, Keywords, Creator, Producer, Created, Modified) and page count. See PDF Document tokens.
