Rename List Fields

These fields can be shown as columns in the Rename List. Use Select fields… to choose visible columns. Many fields also appear as formatting tokens — see Formatting Tokens.

Each field may support:

  • Write — editable via Manual Override / Edit as Name List, and available as a filter Apply target when the Filter Options pane offers that field.
  • Preview — a Before/After (or preview) column variant can be shown; values may also change when related writable fields change (for example File Name Length after renaming).

Fields without Write are read-only.

Basic path and name information.
