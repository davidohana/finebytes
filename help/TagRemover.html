Audio Tag Remover

Removes embedded tag blocks—either selected types, or every TagLib-controlled tag when Remove all embedded tags is checked.

Tag removal cannot be undone with the app Undo control.

Options

  • Remove all embedded tags — Nuclear strip of every TagLib tag type.
  • Tag types to remove — When not removing all, select which modeled blocks to delete.

Examples

song.mp3 (with ID3 tags) >>> song.mp3 (no embedded tags left) song.flac (remove ID3v2 only) >>> (preview error — wrong tag type for container)
