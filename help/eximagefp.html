EXIF Tokens

EXIF and related metadata from image files. Common fields also appear under Jpeg Tag columns.

Date Picture Taken

Formats EXIF Date Taken with a .NET date/time pattern. Missing Date Taken expands empty.

Signature: <exif-date:format-string>

Example: <exif-date:yyyy-MM-dd> — see Date and Time Format Strings.

Metadata Field

Escape hatch for any MetadataExtractor tag by directory alias and tag name or decimal id. Missing tags expand empty.

Signature: <exif:source,name>

  • source — one of: Exif, ExifSub, GPS, IPTC, Canon, Casio, FujiFilm, Nikon, Olympus, Interop, Thumb (case-insensitive).
  • name — tag display name (for example Make) or decimal tag id (for example 271 or 36867).

Examples: <exif:Exif,Make>, <exif:ExifSub,36867>
