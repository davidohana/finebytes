Software components

Magic File Renamer 8 uses (among others):

  • Avalonia UI — cross-platform .NET UI framework used for the desktop shell.
  • TagLib# — reading and writing metadata in many audio and image formats.
  • MetadataExtractor — image and EXIF property extraction (Drew Noakes and contributors).
  • Serilog — structured logging for the UI and console apps.
  • Spectre.Console — command-line parsing and console presentation for mfr (CLI).
  • .NET — runtime and libraries.
