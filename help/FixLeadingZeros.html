Fix Leading 0's

Finds runs of digits and rewrites them so their length matches the target width by adjusting leading zeros. Longer numbers stay unchanged unless surplus zeros are stripped.

Options

  • Number of digits — Target digit count for each number run.
  • Strip surplus leading zeros — When checked, trim extra leading zeros from longer runs down toward the target width when safe.

Examples

track9 >>> track0009 doc1_12 >>> doc1_012 x0007 >>> x007
