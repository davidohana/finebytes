Filters > Space > Separate Capitalized Text

Separate Capitalized Text

Inserts the word separator between camel-case runs and letter–digit boundaries so names split into readable words.

Uses the Space Character separator when that filter appears earlier; otherwise ordinary space.

Options

This filter has no options.

Examples

DandyWorhols01Godless >>> Dandy Worhols 01 Godless song2remix >>> song 2 remix aBc12x >>> a_Bc_12_x

Third example assumes Space Character set the word separator to underscore.
